# LLM B System Prompt 来源与使用说明

整理日期：2026-11-01。实际加载的纯提示词为同目录 `llmb_system.md`，本说明不必拼入system message。

## 本地参考资产

- `prompts/customer_service_system_v1.txt`：已有最终回复模型的15条全局约束，保留事实、权限、商家身份和纯文本输出原则。
- `agent/prompts/llma_system.md`：对齐A/B分工、会话指代、未知值、规则应用及业务工具实际能力。
- `data/processed/official_rules/local_pdf_review_v1/approved_whole_rule_library_v1/approved_whole_rules.jsonl` 及README：当前本地31篇审核整篇来源；本轮重点核对客服服务规范、规则总则与评价规范。来源审核不等于当前有效性核验或检索就绪，不将整库塞入提示词。
- `data/processed/official_rules/governance_v2/`：参考规则治理中的历史版本、特别范围和现行验证边界，不将旧自动分类当作规则已生效的凭证。

## 输入与运行

宿主应传入当前问题和历史对话、LLM A实际取得并选择的事实/规则/说明书证据，以及需要时的真实操作凭证。兼容旧字段fact_context/rule_context与新字段fact_evidence/policy_evidence/manual_evidence；不要把完整隐藏后台或本说明作为用户事实注入。

应用层在调用B前负责充分性、对象范围和终止动作检查；关键证据缺失正常应直接脚本兜底。B中的异常交接规则只是最后防止编造，不意味着用B替代该流程。B不做原生工具调用，也不输出澄清动作JSON。

这是新的候选Prompt，尚未用于第一轮SFT训练或完整模型对照评测。实际采用时保存Prompt哈希及运行版本；旧训练Prompt保留以便复现。该提示词不会将本地尚未就绪的31篇来源自动接入当前search_policies工具；目前工具实际语料仍以其配置为准。
